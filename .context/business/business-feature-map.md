> Focused summary for shift-left testing of **BK-9: TMS-Module | Create modules with nested sub-modules**

**Feature in scope**: FEAT-013 (Module Hierarchy) — CREATE operation only

**What is implemented today:**

- No UI form to create a module

- `parent_module_id` → nullable (root module if null)
- `position` → integer, determines sibling order
- `path` → string (materialized path pattern, e.g. `/root/child/`)
- Depth limit: 6 levels (check if DB trigger or app-level)
- `project_id` → required (module belongs to exactly one project)

**Test data dependency chain:**
```
workspace → project → module (root) → module (child, parent_module_id = root.id)
```
