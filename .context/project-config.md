## Tech Stack

### Frontend
- Framework: Next.js 15 (App Router) — `package.json` `"next": "^15"`
- Language: TypeScript 5.9 (strict mode — `tsconfig.json` `"strict": true`)
- Styling: Tailwind CSS 3.4 (`tailwindcss` devDependency, `postcss` + `autoprefixer`)
- UI primitives: Radix UI (`@radix-ui/react-{dialog,dropdown-menu,tabs,tooltip}`), `cmdk` (command palette), `lucide-react` (icons), `class-variance-authority` + `tailwind-merge` (variant styling), `@dnd-kit/*` (drag-and-drop — module tree, ATC/test reordering), `@tanstack/react-table` (table views), `@monaco-editor/react` (code/step editor), `sonner` (toasts)
- State: not confirmed from `package.json` alone — no Redux/Zustand/Jotai dependency found; likely React Server Components + local state / URL state, consistent with a Next.js App Router app. **Discovery Gap** — not verified by reading component source this pass.

### Backend
- Framework: Next.js 15 Route Handlers (`app/api/v1/**/route.ts`) — no separate API gateway or Express/NestJS layer. Confirmed by `business-api-map.md` §1: "served as Next.js 15 Route Handlers running in Node.js. There is no separate API gateway."
- Language: TypeScript (same codebase as frontend — single Next.js app)
- ORM: none — direct Supabase JS client (`@supabase/supabase-js`, `@supabase/ssr`) calling Postgres via PostgREST/RPC, not an ORM. Business logic that needs atomicity routes through **SECURITY DEFINER RPCs** (`bunkai_create_atc`, `bunkai_update_atc`, `bunkai_create_run`, `bunkai_bootstrap_workspace`, etc. — see `business-api-map.md` §4).
- API contract: OpenAPI 3.x, generated via `@asteasolutions/zod-to-openapi` from `lib/openapi/registry.ts` + sibling `route.openapi.ts` files. Interactive docs at `GET /api/docs`, JSON spec at `GET /api/openapi`.

### Database
- Type: PostgreSQL
- Provider: Supabase (hosted) — Auth (GoTrue), Postgres, Row Level Security, Realtime
- Access: `staging-dbhub` MCP (read-only queries against the live staging schema) — see `.agents/project.yaml` `environments.staging.db_mcp`. A `local-dbhub` MCP is also declared for local dev.
- Schema state (per `business-data-map.md`, verified 2026-08-13 against `staging`): 28 tables in `public` schema, 10 DB triggers, several SECURITY DEFINER RPCs. No ORM migration tool — raw SQL migrations under `supabase/migrations/*.sql`.
