## Tech Stack

Short form; the full stack with versions and evidence is `bun run context:map infra-context --section overview`.

### Frontend
- Framework: Next.js 15 (App Router only), React 19
- Language: TypeScript 5.9 (strict)
- Styling: Tailwind CSS 3.4, shadcn/ui (Radix primitives), lucide-react
- State: no state library; scoped React Context + local and URL state, Supabase Realtime for live updates

### Backend
- Framework: Next.js 15 Route Handlers (`app/api/v1/**/route.ts`), every handler through `withApiHandler()`
- Language: TypeScript (same codebase)
- ORM: none; supabase-js (PostgREST) + SECURITY DEFINER RPCs
- API contract: OpenAPI 3 generated by `@asteasolutions/zod-to-openapi`

### Database
- Type: PostgreSQL
- Provider: Supabase (hosted): Postgres, Auth, Storage, Realtime, Vault. One project backs local, staging and production
- Access: `staging-dbhub` MCP (read-only role `qa_inspector_ro`), used for both `local` and `staging` per `.agents/project.yaml`

### Infrastructure
- Cloud: Vercel (hosting, `after()`, two daily crons in `vercel.json` that fire only on production) + Supabase Cloud
- CI/CD: none in the target's committed trees; Vercel git-integration deploys (inferred). This repo runs its own suites in GitHub Actions
- Monitoring: none (no Sentry, PostHog or APM); JSON access logs in Vercel and `GET /api/v1/health`
